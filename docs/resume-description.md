# Resume Description

## One line
SmartHire AI is a Flask-based recruitment platform that parses resumes and job descriptions, calculates explainable candidate matches, and supports real-time hiring operations.

## Two lines
Built a local AI recruitment platform using Python, Flask, MySQL, SQLAlchemy, scikit-learn, Chart.js, and Flask-SocketIO. Implemented resume/JD parsing, skill extraction, weighted matching, ranking, analytics, interviews, Copilot, RBAC, and security controls.

## ATS bullets
- Built a Flask recruitment platform with local resume/JD parsing, seeded skill extraction, TF-IDF/cosine semantic similarity, weighted candidate scoring, deterministic ranking, and explainable score traces.
- Implemented recruiter analytics, funnel metrics, skill-gap analysis, CSV reporting, interview scheduling with conflict detection, notifications, and Flask-SocketIO realtime updates.
- Added rule-based recruiter Copilot, AI hiring insights, AI audit versioning, RBAC, CSRF protection, secure upload validation, session hardening, and automated tests.
