# User Guide

Recruiters sign in, create jobs, upload job descriptions, manage candidates, review explainable scores, shortlist candidates, schedule interviews, and open Analytics. Interview conflicts are rejected for overlapping recruiter or candidate appointments.

Analytics includes funnel counts, conversion rates, trends, score distribution, job performance, skill gaps, hiring insights, and CSV exports. Copilot answers read-only questions from the current recruiter workspace.

Admins open Workspace and System health for system-wide metrics and runtime checks. Candidates can access only their own profile, resumes, applications, interviews, and notifications.
