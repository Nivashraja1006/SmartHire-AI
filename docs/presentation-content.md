# Presentation Slides

1. **Title:** SmartHire AI; team, guide, and project title.
2. **Introduction:** Recruitment contains repetitive document and coordination work.
3. **Problem Statement:** Manual screening is slow and difficult to audit.
4. **Existing System:** Spreadsheets and disconnected review workflows.
5. **Proposed System:** Local, explainable, real-time recruitment platform.
6. **Objectives:** Parse, match, rank, coordinate, analyze, and protect.
7. **System Architecture:** Browser -> Flask -> services -> AI -> SQLAlchemy/MySQL.
8. **Technology Stack:** Python, Flask, MySQL, SQLAlchemy, Socket.IO, Chart.js.
9. **AI Pipeline:** Text validation, parsing, skills, matchers, weighted score, explanation.
10. **Matching and Ranking:** Six components, score trace, recommendation tiers, tie-breaking.
11. **Realtime Architecture:** Events, recruiter rooms, notifications, live dashboard updates.
12. **Analytics and Copilot:** Funnel, trends, skill gaps, CSV reports, rule-based queries.
13. **Security and Fairness:** RBAC, CSRF, secure uploads, safe sessions, job-relevant signals.
14. **Results and Demo:** 20 automated tests passed; show fictional live workflow.
15. **Conclusion and Future Scope:** Human-controlled explainable recruitment; future multilingual and enterprise capabilities.
